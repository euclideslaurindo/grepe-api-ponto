Pasta do projeto:

IMPORTANTE - BANCO DE DADOS:
  - ddl-auto=none (nao cria nem altera tabelas/colunas)
  - Relatorio: apenas SELECT (leitura)
  - Troca de senha (se usar): UPDATE somente na coluna pass

ERRO "Communications link failure" / Connection refused:
  = MySQL NAO esta aceitando conexao em localhost:3306
  1. Inicie o servico MySQL (services.msc -> MySQL -> Iniciar)
     ou ligue MySQL no XAMPP/WAMP
  2. Confirme que existe o banco grepe_test
  3. Teste no CMD: mysql -h 127.0.0.1 -P 3306 -u gream -p grepe_test
  4. Se o banco estiver em OUTRO servidor, altere em application.properties:
     spring.datasource.url=jdbc:mysql://IP_DO_SERVIDOR:3306/grepe_test?useSSL=false

COMO RODAR (mais facil):
  1. Ligue o MySQL (banco grepe_test)
  2. De duplo clique em RODAR.bat
  3. Abra http://localhost:8085/

COMO RODAR (NetBeans):
  1. Abra esta pasta como projeto Maven
  2. Botao direito no projeto -> Clean and Build
  3. Run em GrepeApiApplication.java
